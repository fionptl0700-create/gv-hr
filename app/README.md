# 綠谷國際 GV STUDIO — 線上人資考勤系統

台北同仁正常班（勞基法）· 上班 09:00–18:00 · 特休**週年制** · 通知走 **LINE**

## 技術

- Next.js 14（App Router）+ TypeScript + Tailwind
- Prisma ORM +（開發）SQLite；正式環境改 PostgreSQL
- Server Actions（無額外 API 層）

## 快速開始

```bash
cd gv-hr
npm install
npm run setup     # prisma generate + db push + 匯入種子資料（公司/部門/假別/行事曆/示範員工）
npm run dev       # http://localhost:3000
```

## 已實作模組（M1 範圍）

| 區塊 | 內容 |
|---|---|
| 打卡 | 上/下班、外出、加班段打卡，記錄 GPS / IP |
| 請假 | 勞基法 **23 種假別**（`src/lib/leave-catalog.ts`），附件規則（必附／條件式／不得要求／得要求）、額度檢核、多關簽核 |
| 特休引擎 | 勞基法 §38 週年制，依到職日自動給假（`src/lib/annual-leave.ts` + 測試） |
| 加班 | §24 費率試算、§32 月上限（46/54/138）預警、§32-1 補休時數銀行 |
| 出差 / 外出 / 遠距 | 三種申請單，國外／逾 3 日／逾預算自動加簽 |
| 簽核中心 | 待辦、核准 / 駁回、簽核歷程；結果經 `notify()` 推播（LINE 未設定則排入佇列） |
| 人資大表 | 員工主檔清單、單筆編輯（薪資、勞健保、角色、班別、異動歷程、稽核） |
| 薪資試算 | 依當月出勤自動計算：請假扣薪（無薪／半薪）、遲到早退按比例扣、曠職扣、加班費加項、全勤獎金判定、實發淨額 |
| 報表 | 月出勤彙總（應出勤日 / 遲到 / 早退 / 曠職 / 請假 / 加班） |

## 法遵重點（已內建對應邏輯）

- 特休週年制、未休折現、施行細則 §24-1 告知義務（`annual-leave.ts` / 通知範本）
- 加班 §24 / §32 / §32-1
- 遲到早退僅「按未提供勞務時間比例」扣發，不另立罰款（`src/lib/payroll.ts`）
- 出勤紀錄逐日至分鐘、稽核軌跡（`AuditLog`）、特種個資存取控管（診斷證明僅 HR + 直屬主管）
