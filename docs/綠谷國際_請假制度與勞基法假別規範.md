# 綠谷國際 GV STUDIO｜請假系統 — 勞基法假別規範

> 特休制度：**週年制**（自到職日起算）｜通知渠道：**LINE**
> 本文件為系統假別主檔（`leave_types`）的設定依據。所有日數、工資、附件規定以中華民國現行法令為準，實際適用請以最新勞動部函釋為主。

## 二、特別休假日數（勞基法 §38，週年制）

| 年資 | 特休日數 |
|---|---|
| 滿 6 個月，未滿 1 年 | 3 日 |
| 滿 1 年，未滿 2 年 | 7 日 |
| 滿 2 年，未滿 3 年 | 10 日 |
| 滿 3 年，未滿 5 年 | 每年 14 日 |
| 滿 5 年，未滿 10 年 | 每年 15 日 |
| 滿 10 年以上 | 每滿 1 年加 1 日，上限 30 日 |

**週年制規則**
- 給假基準日 = 員工到職日之週年。
- 每個週年重新計算額度，前一週年度未休日數 → 折算工資發給（或經勞資書面協商遞延至次一週年度，次年度終結仍未休完仍須發工資）。
- 到職滿 6 個月當日給 3 日；滿 1 年當日給 7 日；其後於每個到職週年日給假。
- 雇主應於員工符合特休條件之日起 **30 日內**，以書面（可電子/LINE 推播並留存紀錄）告知可休日數及期限（施行細則 §24-1）。

**計算函式（虛擬碼）**
```
function annualLeaveDays(hireDate, asOf):
    months = 完整月數(hireDate → asOf)
    years  = floor(months / 12)
    if months < 6:   return 0
    if months < 12:  return 3
    if years < 2:    return 7
    if years < 3:    return 10
    if years < 5:    return 14
    if years < 10:   return 15
    return min(15 + (years - 9), 30)   # 10年→16 … 24年起→30
```

## 三、附件（證明文件）驗證規則

| 規則 | 說明 |
|---|---|
| **必附** | 婚假、喪假、產假、產檢假、陪產檢及陪產假、育嬰留停、公假、公傷病假 → 送單時未上傳附件則不可送出（可先送、限期補件，逾期自動轉事假或標記異常） |
| **條件式必附** | 普通傷病假 **逾 3 日**（或單筆跨假日致實際 > 3 日）、或 HR 個案要求 → 需診斷證明 |
| **不得要求** | 生理假 → 系統不提供、也不得要求附件欄位 |
| **得要求** | 事假、家庭照顧假 → 附件為選填，主管/HR 可於簽核時要求補件 |
| 檔案格式 | PDF / JPG / PNG，單檔 ≤ 10 MB，儲存加密，保存期限比照出勤紀錄 5 年 |
| 個資 | 診斷證明屬特種個資，僅 HR 與該員直屬簽核主管可檢視，存取寫入 `audit_logs` |

## 四、請假流程（系統）

1. 員工於系統/LINE 選假別 → 帶出該假別的**額度、剩餘、附件規則**。
2. 系統即時檢核：額度是否足夠、是否逾法定上限、日期是否與班表/既有假單衝突、附件是否齊備。
3. 送出 → 依假別設定的簽核關卡（直屬主管 → 部門主管 → HR；產假/育嬰留停/公傷病假強制 HR 覆核）。
4. 每關卡透過 **LINE Messaging API** 推播代辦；逾 N 日未簽核自動提醒 / 升級。
5. 核准 → 扣抵 `leave_balances`、寫入 `attendance_daily`、回推 LINE 通知員工。
6. 駁回 / 銷假 → 還原額度，通知員工。
7. 全程寫入 `audit_logs`。

## 五、與出勤 / 異常的整合

- 已核准假單當日 → 出勤結算不判「缺卡 / 曠職」。
- 病假、事假、家庭照顧假累計達門檻 → 影響全勤獎金（依公司辦法，不得作為考績唯一負面依據）。
- 特休即將到期（週年日前 60 / 30 日）→ LINE 提醒員工與 HR。
- 育嬰留停 / 留職停薪期間 → 員工狀態轉「停薪留職」，停止出勤結算與特休給假，復職日續算年資。
